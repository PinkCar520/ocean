# Ocean 产品设计开发规范约定

适用于 Ocean Web 和 Desktop。全局约定用于新功能，组件规格用于对应场景。任务明确调整某项规格时，以任务要求为准，并在交付中说明差异。本文的尺寸均为 CSS px。

## 1. UI 设计

### 字体、颜色与留白

| 元素 | 规范 |
| --- | --- |
| 界面字体 | 使用 `font-sans`（Inter）。展示型标题用 `font-display`（Manrope）。中英文沿用共享字体回退。 |
| 浮层标题 | 16px / 24px，字重 600。 |
| 会话标题、菜单项、输入框 | 14px / 20px。会话标题和成员名称用 500，普通标签、菜单项和输入文字用 400。 |
| 浮层说明 | 14px，行高 1.625，字重 400，用 `muted-foreground`。 |
| 辅助标签、状态、短说明 | 12px / 16px。普通说明用 400，分区标签用 500。 |
| 分享操作按钮 | 12px / 20px，字重 400。Invite、Cancel、Enable public link、Stop sharing、Copy link 共用字体规格。 |
| 颜色 | 正文用 `foreground`，辅助文字用 `muted-foreground`，浮层用 `card`，分隔线用 `border`。品牌主操作用 `primary`，危险操作用 `destructive`。以共享主题变量为准。 |
| 间距 | 同一行内相关元素间距通常为 8–12px，分享浮层主要区块间距 16px，左右内边距 20px。用留白建立层级，分隔线区分访问权限和底部操作。 |

文案简短，长标题或邮箱可截断，并提供查看完整文本的方式。交互控件应明确默认、悬浮、键盘聚焦、激活和禁用状态。图标按钮提供可访问名称，悬浮和键盘聚焦提示表达点击后的动作。

### 聊天组件规格

| 控件 | 规范 |
| --- | --- |
| 短文字 Tooltip | 参考「登录设备」。复用共享 Tooltip 的 inverse 样式，黑底白字、中等阴影，圆角 6px，左右内边距 12px、上下 6px。文字 12px / 16px，字重 400。悬浮延迟 250ms，键盘聚焦时直接显示，距触发控件 4px。Tooltip 层级随所在浮层，点击打开明细时收起提示。 |
| 聊天 Header | 高 56px。有会话时显示项目名（如已关联）、会话标题和操作入口。标题、分享及侧栏按钮按控件中心对齐。 |
| 左右侧栏按钮 | 点击区 32 × 28px，图标 18 × 18px。使用无箭头的左右镜像面板图形，展开时加深面板填充。提示示例为「展开左侧栏」。 |
| Web 侧栏按钮 | 左右按钮距对应页面边缘 12px。左栏收起时，会话标题给按钮留出空间。 |
| macOS 侧栏按钮 | 窗口模式下，左按钮在三色窗口按钮右侧，按图标中心对齐。全屏时，两侧按钮在 56px 顶栏内垂直居中。 |
| 分享浮层 | 锚定 Header 右上角分享按钮，基准宽 432px、外圆角 16px，窄窗口时收缩。标题下用简短文案说明快照范围。右上角关闭按钮点击区 28 × 28px，× 图标 20 × 20px。 |
| Email 输入框 | 高 28px，字号 14px，圆角 6px，占用邀请行剩余宽度。占位文字为 Email。默认 `foreground/5` 背景、无描边，键盘聚焦为 1px 主色描边。 |
| 分享操作按钮 | 高 28px，圆角 6px。Invite 和 Enable public link 用品牌主色，悬浮加深。Cancel 默认浅灰底，悬浮加深。Copy link 在底部右侧，黑底白字，链接图标 14px。Stop sharing 在底部最左侧，默认淡粉底、红字，悬浮加深。 |
| 访问权限下拉 | 高 36px，填满左侧图标之外的剩余宽度。文字 14px，左右留出内边距，箭头靠右。默认透明、无边框，悬浮和聚焦用 `foreground/5` 灰底。图标底座 32 × 32px，锁和地球图标 15px。 |
| 公开访问确认区 | 白底、细边框、圆角 12px、内边距 10px。说明用 12px。Cancel 与 Enable public link 靠右并排。 |
| 成员头像与列表 | 头像 32 × 32px，优先使用账户头像。缺失或加载失败时，用大写邮箱首字母和虚线圆框。名称旁显示 (You) 或 (Invited)，Owner 标签靠右。受邀者行保留移除操作，复制链接统一从浮层底部操作。成员较多时优先滚动列表。 |
| 会话内搜索 | 浮层位于消息区右上方，避开 Header 点击区域。输入框高 32px、基准宽 176px，文字 14px。计数用 12px 等宽数字。上一处、下一处和关闭使用 32 × 32px 点击区、16px 图标。输入框内省略清空 ×。 |

## 2. 交互设计

| 场景 | 行为 |
| --- | --- |
| 首次发送与流式回复 | 首条用户消息进入会话后显示 Header。小星标只在等待首段回复正文时显示，正文出现即收起。 |
| 会话重命名 | 双击 Header 标题或在标题菜单选 Rename，进入同一个原位编辑状态。Enter 提交，Escape 取消。为空、保存中或失败时提供明确反馈，保留待修正的输入。 |
| 改变项目关联 | 从标题菜单打开右侧二级项目选择器，支持搜索现有项目，当前项目显示勾选。新建项目沿用原有入口。窗口边缘空间不足时由浮层定位组件调整。 |
| 悬浮预览侧栏 | 侧栏收起时，鼠标进入按钮 150ms 后临时展开，移入面板保持展开，离开有效区域 180ms 后收回。窗口边缘不触发。 |
| 点击侧栏按钮 | 点击切换常驻展开／收起，并清理悬浮计时。预览在进场、停留、退场时均覆盖于聊天区上方。只有常驻切换才改变聊天布局。 |
| 打开和关闭浮层 | 分享浮层支持关闭按钮、Escape 和点击外部关闭。键盘可达所有操作，关闭后焦点回到合理的触发位置。分别验证可见性和可点击性。 |
| 会话内搜索 | 打开即聚焦，高亮当前会话正文的全部命中，并区分当前命中。Enter 下一处，Shift＋Enter 上一处，Escape 关闭。中文输入法组字期间等待提交。侧栏 Search Chats 用于查找会话。 |
| 分享操作反馈 | 请求中避免重复提交。锁和地球跟随权限选项。公开访问须经确认后启用。错误提示靠近相关操作，保留重试路径。复制成功后提供简短反馈。 |

## 3. 产品规则

- **Ask 与工具审批分别处理。** 两张卡都放在输入框上方。Ask 收集缺失的目标、偏好或选择，答案交回当前 Run。工具审批展示具体操作及目标，文件写入提供拟写入内容预览，用户可允许一次或拒绝。提交期间禁用重复操作，失败时在卡片内提示重试。
- **Pin 是会话置顶。** Pin 后进入侧栏 Pinned 区，Unpin 后回到普通会话分组。首次成功 Pin 后给出可关闭的引导，提示内容应对应已支持的操作。收藏有独立的产品语义。
- **项目关联属于会话。** 添加、更换、移除项目后，Header 和项目选择器显示一致的归属。操作期间保留当前会话上下文。
- **分享对象是当前会话分支的只读快照。** 分享页展示经授权的快照，复用聊天消息、Markdown、代码块和长消息折叠。编辑、重试和继续对话等操作由原始会话承担。
- **访问权限与登录状态分别处理。** 仅受邀访问由服务端校验身份与邀请。公开链接允许匿名读取已授权的公开快照。已登录且有权访问分享页时，显示访问者自己的聊天侧栏。只有具备原始会话访问权限的人才看到「打开原始会话」。
- **公开访问与单人邀请独立撤销。** Stop sharing 关闭公开链接，移除受邀者撤销该人的访问。失效链接显示带 Ocean 标识的专用状态页，说明链接可能失效或当前账号可能无权访问，并提供返回入口。正文和原始会话信息始终由服务端鉴权。
- **术语和入口保持一致。** Share chat 入口在 Header 右上角。标题菜单提供会话管理和项目关联。Header、侧栏、菜单、提示和本地化文案统一使用 Pin／Unpin、Invite、Copy link 等已约定术语。

## 4. 开发与交付

1. **复用共享组件和 token。** 先检查 `packages/ui` 的控件、主题和本地化资源。左右侧栏复用图标和预览逻辑，分享页复用消息渲染。
2. **明确状态和层级。** 区分常驻、预览、加载、失败和禁用。核对 Header、按钮、工具提示、浮层和 macOS 拖拽区的绘制顺序与点击区域。
3. **把平台差异留在应用外壳。** Web 和 Desktop 共用产品行为，Desktop 处理窗口控制、全屏与拖拽区域。侧栏预览动画始终作用于脱离布局的浮层。
4. **检查旧数据与迁移。** 数据或权限语义变化时，处理旧数据兼容、迁移与失败重试。交付记录区分迁移文件就绪、运行库已执行迁移、运行库结果已验证。

| 改动范围 | 验收场景 |
| --- | --- |
| Header／侧栏 | Web、macOS 窗口、macOS 全屏。检查新建及已有会话、左右展开及收起、按钮可见可点击、提示和窗口拖拽。鼠标从按钮移入浮层再移出时，正文、滚动条和输入框不横移。 |
| 搜索／菜单 | 鼠标与键盘、中文输入法、无结果与多结果、窄窗口、浮层层级、关闭和焦点返回。 |
| 分享 | Owner、受邀者、已登录未受邀者、匿名访客。检查两种访问权限、头像回退、复制链接、撤销与旧链接失效。 |
| 发布 | 分别记录类型检查、实际界面验证和迁移结果。注明已验证的端、窗口模式和角色，以及仍待验证的场景。 |
