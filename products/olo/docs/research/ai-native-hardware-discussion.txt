好。那我们就不把它当成“几个 AI 硬件产品的盘点”，而是把它当成一个**未来产业地图**来推。

我先给你一个核心判断：

# 2026–2035：AI 原生硬件演化地图

> **下一代计算平台的竞争，很可能不是“谁做出更好的设备”，而是谁掌握了 AI Agent 从认知 → 感知 → 决策 → 行动的完整闭环。**

现在这个趋势已经越来越明显：宇树把自己定位在具身智能，并同时推进人形机器人、四足机器人、UnifoLM 等软硬件体系；([宇树科技—全球四足机器人行业开创者][1])
而 OpenAI 在 2026 年也已经开始出现面向 Agent 的专用硬件探索。([gizmodo.jp][2])

---

## 一、先把整个世界重新分类

我不建议按照：

> 手机 / 汽车 / 机器人 / AI

来分类。

应该按照 **AI 的身体结构** 来分类：

```text
                         ┌─────────────────────┐
                         │      AI Agent       │
                         │                     │
                         │  理解 / 记忆 / 决策   │
                         └──────────┬──────────┘
                                    │
              ┌─────────────────────┼─────────────────────┐
              ↓                     ↓                     ↓
         Interface                Body                  Space
          入口                     身体                   空间
              │                     │                     │
        ┌─────┴─────┐        ┌──────┴──────┐       ┌──────┴──────┐
        │           │        │             │       │             │
     AI终端       可穿戴    机器人        机械臂    汽车         家庭
        │           │        │             │       │             │
      小方块       眼镜      宇树          工业     Cybercab     AI Home
```

这时候你会发现：

### 魅族小方块

不是“小手机”。

它真正有价值的地方是：

> **把 AI 从手机 App 中抽离出来。**

---

### 宇树

也不仅仅是“机器人公司”。

它真正争夺的是：

> **给 AI 一个身体。**

宇树目前已经同时覆盖四足机器人、人形机器人、机械臂、感知组件和 UnifoLM 等方向。([宇树科技—全球四足机器人行业开创者][3])

---

### Cybercab

也不只是“无人驾驶汽车”。

它代表的是：

> **给 AI 一个可以移动的物理空间。**

这三个东西一旦放到同一张图里，就突然非常有意思了。

---

# 二、真正的第一阶段：2024–2027

## AI 从 App 里“逃出来”

过去：

```text
人
 ↓
手机
 ↓
App
 ↓
功能
```

现在开始变成：

```text
人
 ↓
AI Agent
 ↓
调用各种能力
 ↓
设备执行
```

所以：

**App-centric → Agent-centric**

这是第一道分水岭。

---

# 三、2027–2030：Agent 开始拥有“身体”

这是我认为最关键的阶段。

现在的 AI 最大问题是什么？

> **它知道很多东西，但不能直接改变现实世界。**

你告诉 ChatGPT：

> “帮我把房间整理一下。”

它可以告诉你怎么整理。

但是它不能真的去整理。

如果接入机器人：

```text
你：
“把客厅整理一下。”

        ↓

AI Agent

        ↓

视觉理解
空间理解
物体识别
任务规划

        ↓

机器人

        ↓

拿起杯子
移动桌椅
清理垃圾
```

这时候 AI 才真正开始拥有：

# **Action**

也就是**行动能力**。

所以：

> LLM → Agent → Embodied Agent

是一个非常重要的演化链。

---

# 四、然后出现一个更加疯狂的东西

## Agent 不再只有一个身体

这才是我认为最值得关注的未来。

比如你只有一个 Agent：

```text
                   我的 AI Agent
                         │
          ┌──────────────┼──────────────┐
          ↓              ↓              ↓
       小方块          宇树机器人       Cybercab
       Interface         Body            Space
          │              │              │
       交流/控制        执行动作        移动/运输
```

你根本不需要分别操作三个设备。

你只需要：

> **告诉 Agent 你想干什么。**

---

例如：

**“我下午三点要去机场。”**

Agent 自动：

1. Cybercab 到楼下
2. 计算路线
3. 判断交通情况
4. 机器人帮你拿行李
5. 小方块提醒你登机
6. 到机场后 Agent 继续管理行程

这时候：

**汽车、机器人、终端已经不是三个产品。**

它们只是：

# Agent 的不同“执行器”。

---

# 五、所以 Apple 的真正对手可能发生变化

这是最有意思的一层。

今天：

> Apple 的核心优势 = iPhone + iOS + App Store + Ecosystem

但未来：

```text
             AI Agent OS
                  │
      ┌───────────┼───────────┐
      ↓           ↓           ↓
    Phone       Robot        Car
      ↓           ↓           ↓
    Glass       Home        Wearable
```

这时候真正重要的东西就变成：

> **谁控制 Agent 的身份、记忆、权限、支付、数据和设备调度。**

这比“谁的手机卖得多”重要得多。

---

# 六、于是会出现五个超级玩家阵营

我暂时这么看：

| 阵营         | 最强资产                      | 可能争夺的位置     |
| ---------- | ------------------------- | ----------- |
| **Apple**  | OS + 芯片 + 终端 + 生态         | Agent OS    |
| **OpenAI** | Frontier Model + Agent    | AI 大脑       |
| **Tesla**  | FSD + 汽车 + 机器人            | Physical AI |
| **Google** | Search + Gemini + Android | Agent 信息入口  |
| **中国硬件阵营** | 制造 + 电动车 + 机器人 + IoT      | Agent 身体    |

而中国这里面又可以拆：

```text
华为
 ↓

机器人 + 具身智能

BYD
 ↓
汽车 + AI + 机器人

小鹏
 ↓
汽车 + AI + 机器人
```

所以中国真正有意思的地方在于：

> **中国拥有把 AI 大规模装进物理世界的制造能力。**

宇树目前甚至已经把产品线扩展到 H2 Plus、H2-D、As2-W 等新型号，明显在从展示型机器人向更多实际应用推进。([プレスリリース・ニュースリリース配信シェアNo.1｜PR TIMES][4])

# 七、但这里存在一个巨大的分叉

未来可能出现两种路线：

### 路线 A：AI 控制设备

```text
人
 ↓
AI
 ↓
手机
 ↓
机器人
 ↓
汽车
```

设备还是设备。

AI 只是中间层。

---

### 路线 B：AI 直接成为“设备层”

```text
                 AI Agent
                     │
          ┌──────────┼──────────┐
          ↓          ↓          ↓
        Robot       Car       Home
          ↓          ↓          ↓
          └──────────┼──────────┘
                     ↓
                  Reality
```

这时候：

**设备品牌的重要性下降。**

Agent 品牌的重要性上升。

这就是为什么我认为：

# **AI Agent OS 可能是 2030 年前后最大的科技平台战争。**

---

# 八、而魅族“小方块”为什么值得特别研究？

因为它踩到了一个非常关键的产品哲学：

> **不要再让用户“找 App”。**

传统手机：

```text
我要订餐
 ↓
打开 App
 ↓
搜索
 ↓
选择
 ↓
支付
```

Agent：

```text
“帮我订一份附近的晚餐。”
             ↓
          Agent
             ↓
       自动完成任务
```

那么手机最重要的东西就不再是：

> **屏幕多大、芯片多快、摄像头多少亿。**

而变成：

> **我能不能随时叫到我的 Agent？**

这就是“小方块”这种产品形态真正值得研究的地方。
